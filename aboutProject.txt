WR & Slips Mobile Application

Version: 1.0

1. Project Overview

The WR & Slips application is a Flutter-based mobile application designed to provide users with quick access to WR-related documents, circulars, PDFs, and slips. The application supports two types of users:

- User
- Admin

Users can browse and download documents, while administrators can manage all content within the application.

---

2. Objectives

- Provide easy access to WR documents.
- Organize documents into categories.
- Allow users to read and download PDFs.
- Allow administrators to upload and manage documents.
- Provide a clean and user-friendly interface.

---

User Journey

1. Open the app.
2. Splash screen appears.
3. User logs in or registers.
4. User selects the User role.
5. User selects a railway zone.
6. User reaches the Home screen.
7. User selects one of the five sections.
8. User opens either PDFs or Slips.
9. User reads the document and can download it.

---

Admin Journey

1. Open the app.
2. Log in as Admin.
3. Open the Home screen.
4. Select a section.
5. View the document list.
6. Add, edit, rename, or delete PDFs and slips.
7. Save changes so users see the updated content.

STUDY / BOOK LIBRARY — PUBLIC API (for Flutter / Android app)
================================================================

Base URL (production): https://study.mycbt.in/api/v1
Base URL (local dev):  http://localhost/books/public/api/v1

No authentication required — all endpoints are public, read-only.
Rate limit: 120 requests/minute per IP.
All responses are JSON. Errors (404, validation, etc.) also come back as JSON.


ENDPOINTS
---------

GET /home
    Home screen data: recently added books + books grouped by category.
    No query params.

GET /books
    Paginated / filterable book list (for a Browse screen).
    Query params (all optional):
      q             search text (title / description / tags)
      category_id   filter by category id
      department_id filter by department id
      language_id   filter by language id
      zone_id       filter by zone id
      exam_id       filter by exam id
      per_page      results per page, default 20, max 50

GET /books/search?q=...
    Lightweight typeahead search (no pagination). Use this for a live
    "search as you type" box.
    Query params:
      q       search text (required — empty q returns an empty list)
      limit   max results, default 15, max 30

GET /books/{slug}
    Full detail for one book, plus a "related" list of similar books.
    Visiting this endpoint increments the book's view counter.

GET /categories
GET /departments
GET /languages
GET /zones
GET /exams
    Lookup lists for filter dropdowns. Each item is {id, name, slug}
    except /languages, which is {id, name, code}.


BOOK OBJECT — FIELD REFERENCE
------------------------------

id                 number
slug               string   — use this in URLs, not id
title              string
description        string or null
year               number or null
pages              number or null
tags               array of strings
views              number
views_short        string   — e.g. "1.2K", "13", for display
downloads          number
file_size          number   — bytes
file_size_human    string   — e.g. "8.6 MB"
category           {id, name, slug} or null
department         {id, name, slug} or null
language           {id, name, code} or null
zone               {id, name, slug} or null
exam               {id, name, slug} or null
cover_url          string or null  — book cover image
file_url           string   — direct PDF stream, use for in-app PDF viewer
download_url       string   — triggers a download + increments download count
web_url            string   — opens the book on the website (for "view on web")
created_at         string   — ISO 8601 timestamp
added_human        string   — e.g. "2 days ago"

EXAMPLE — GET /books?per_page=2  (paginated list)
---------------------------------------------------
{
  "data": [
    { "id": 52, "slug": "2da355zc67-sr-clerk-stores-set-a", "title": "...", "...": "same book shape as above" },
    { "id": 51, "slug": "sr-clerk-stores-set-a-3", "title": "...", "...": "same book shape as above" }
  ],
  "links": {
    "first": "https://study.mycbt.in/api/v1/books?per_page=2&page=1",
    "last":  "https://study.mycbt.in/api/v1/books?per_page=2&page=2",
    "prev": null,
    "next": "https://study.mycbt.in/api/v1/books?per_page=2&page=2"
  },
  "meta": {
    "current_page": 1,
    "last_page": 2,
    "per_page": 2,
    "total": 3
  }
}
Use meta.current_page / meta.last_page for infinite scroll (fetch next
page while current_page < last_page).
